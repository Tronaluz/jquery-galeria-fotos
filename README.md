# Galeria de Fotos

Uma aplicação web interativa que permite ao usuário visualizar e adicionar imagens em uma galeria utilizando jQuery.

## Descrição

Esta Galeria de Fotos é uma aplicação web desenvolvida com HTML, CSS e jQuery que proporciona uma experiência intuitiva para visualização e adição de novas imagens. A interface apresenta uma galeria responsiva com efeito de hover nas imagens e um formulário simples para inclusão de novas fotos através de URLs.

## Funcionalidades

- **Visualização de Imagens**: Exibe imagens em formato de galeria
- **Adição de Novas Imagens**: Através de URL externa
- **Efeitos de Transição**: Animações suaves utilizando jQuery
- **Visualização em Tamanho Real**: Link para abrir cada imagem em tamanho completo
- **Interface Responsiva**: Layout adaptável com flexbox

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- jQuery 3.7.1
- Google Fonts (Roboto)

## Configuração & Instalação

1. Clone o repositório:
   ```
   git clone https://github.com/seuusuario/galeria-fotos.git
   ```
2. Abra o arquivo `index.html` no seu navegador para utilizar a aplicação.

## Como Usar

1. Ao abrir a aplicação, você verá a galeria com as imagens pré-carregadas
2. Clique no botão "Nova imagem" no cabeçalho para exibir o formulário
3. Insira a URL da imagem desejada no campo de texto
4. Clique em "Adicionar" para incluir a nova imagem na galeria
5. Para cancelar a adição, clique no botão "Cancelar"
6. Passe o mouse sobre as imagens para revelar o link "Ver imagem em tamanho real"

## Características do Design

- Cabeçalho em roxo com destaque em azul escuro
- Formulário retrátil para adicionar novas imagens
- Efeito de overlay ao passar o mouse sobre as imagens
- Animações suaves de exibição e ocultação de elementos
- Layout responsivo com flexbox
